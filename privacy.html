1. About ClipScope

ClipScope is a desktop analytics application intended to help creators understand the performance of their own TikTok account and public videos.

2. Information processed

If a user connects a TikTok account, ClipScope may process information made available through TikTok's authorized developer interfaces and the permissions approved by the user. Depending on those permissions, this may include basic profile information, account statistics, public video information, and video performance statistics.

3. TikTok login

ClipScope is designed to use TikTok's official authorization flow. Users should not enter or send their TikTok password directly to ClipScope. TikTok may issue authorization tokens that allow approved requests on the user's behalf.

4. Local storage

The desktop version is designed to store imported analytics data, application settings, and authorization information locally on the user's computer whenever possible.

5. Use of information

Information is used to display statistics, compare content performance, generate analytics and insights for the connected creator, maintain the TikTok connection, and troubleshoot the application.

6. Sharing

ClipScope is not intended to sell personal information. Data may be transmitted to TikTok when required to use TikTok's APIs. If future versions add optional cloud services, this policy must be updated before those services are used.

7. Retention and deletion

Locally stored ClipScope data can be removed by deleting it from the application or its local data directory. A user can also revoke ClipScope's TikTok access through the relevant TikTok account controls.

8. Security

Reasonable technical measures should be used to protect locally stored credentials and authorization tokens. No system can guarantee absolute security.

9. Changes

This policy may be updated as ClipScope develops.
